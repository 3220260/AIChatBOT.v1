# VerBot (Sofia)

Node/Vercel chatbot backend + static frontend for the Sofia assistant.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Tests

```bash
npm test
```

## Required Environment Variables

- `GEMINI_API_KEY`
- `GEMINI_MODEL`
- `GEMINI_MAX_OUTPUT_TOKENS`
- `GEMINI_THINKING_BUDGET`
- `DEBUG`

## Validation

```bash
npm run check
```
